# CSRF Fix - 2026-05-17

## Objective
Fix CSRF (Cross-Site Request Forgery) vulnerabilities and form security issues on popsouq.com website.

## Issues Found & Fixed

### 1. Duplicate ID Attributes in Forms
**Problem**: All 4 HTML forms had duplicate `id` attributes (e.g., `id="name"  id="name"`) which could cause:
- HTML validation errors
- JavaScript selection issues
- Potential security vulnerabilities

**Files Fixed**:
- ✅ contact.html (lines 128-152)
- ✅ contact-en.html (lines 129-149)
- ✅ index.html (lines 353-377)
- ✅ index-en.html (lines 329-353)

**Fix Applied**: Removed duplicate id attributes, ensured each form field has unique id matching its label's `for` attribute.

### 2. Missing Textarea ID
**Problem**: The message `<textarea>` was missing the `id="message"` attribute, causing the `<label for="message">` to not work properly.

**Files Fixed**: All 4 files listed above.

**Fix Applied**: Added `id="message"` to all message textarea fields.

### 3. Missing Security Headers (CSRF Protection)
**Problem**: No `.htaccess` file existed to set security headers that protect against:
- Clickjacking attacks (CSRF vector)
- MIME-type sniffing
- XSS attacks
- Referrer leakage

**Fix Applied**: Created `.htaccess` file with:
- `X-Frame-Options: DENY` - Prevents clickjacking
- `X-Content-Type-Options: nosniff` - Prevents MIME sniffing
- `Referrer-Policy: strict-origin-when-cross-origin` - Controls referrer info
- `Content-Security-Policy` - Mitigates XSS and injection attacks
- File access restrictions - Prevents access to sensitive files (.env, .git, etc.)
- Browser caching rules - Optimizes performance
- Gzip compression - Improves load times

## Forms Using web3forms

All forms submit to `https://api.web3forms.com/submit` with:
- ✅ POST method (prevents CSRF via GET)
- ✅ Honeypot field (`botcheck`) - Prevents automated submissions
- ✅ access_key authentication
- ⚠️ PLACEHOLDER access_key - Needs to be replaced with real key before deployment

## Security Headers Added

```apache
# Prevent clickjacking
Header always set X-Frame-Options "DENY"

# Prevent MIME-type sniffing
Header always set X-Content-Type-Options "nosniff"

# Control referrer information
Header always set Referrer-Policy "strict-origin-when-cross-origin"

# Content Security Policy
Header always set Content-Security-Policy "default-src 'self'; script-src 'self' 'unsafe-inline' https://staticmap.openstreetmap.de; style-src 'self' 'unsafe-inline'; img-src 'self' https: data:; font-src 'self'; connect-src 'self' https://api.web3forms.com; frame-src 'self';"
```
